# Analysis data

`analysis_matrices/` contains the three analysis populations used in the manuscript. `design/` contains deterministic measurement-allocation ledgers. `pre_update_predictions/` contains predictions generated before target-label updating. `provenance/` contains the research-level source map for the historical literature matrix.

Columns prefixed with `Analysis_` are the finalized harmonized values used by the executable analyses. Where both an original/reporting field and an `Analysis_` field are present, the latter is the analysis value used by the code. Variable definitions are provided in `docs/DATA_DICTIONARY.md`.
